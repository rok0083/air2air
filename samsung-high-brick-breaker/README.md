# 🧱 삼성고동문회 벽돌깨기

이택형 · 성승현 · 우상봉 · 강현수 · 황진석 · 강동균 — 여섯 동문의 이름을 벽돌로 세워 두고 깨는 모바일 벽돌깨기 게임입니다.

**플레이:** https://rok0083.github.io/air2air/samsung-high-brick-breaker/

카카오톡으로 링크를 보내면 미리보기 카드(제목·설명·썸네일)와 함께 열립니다.

## 게임 방법

- 화면 아무 곳이나 **드래그**하면 패들이 따라옵니다.
- **탭**하면 공이 발사됩니다.
- 벽돌을 깨면 점수가 오르고, 패들에 닿기 전까지 연속으로 깨면 **콤보 배수**가 붙습니다(최대 x5).
- 3개의 스테이지를 모두 깨면 클리어. 위쪽 벽돌은 여러 번 맞혀야 깨집니다.
- 생명은 3개(♥♥♥). 공을 놓치면 하나씩 줄어듭니다.
- 데스크톱에서는 ←/→ (또는 A/D)로 패들, Space로 발사, P/Esc로 일시정지.

## 특징

- **모바일 최적화**: `100dvh` 세로 화면, `touch-action: none`으로 드래그 중 스크롤·당겨서 새로고침 없음, 안전영역(`safe-area-inset`) 대응
- **고해상도 캔버스**: `devicePixelRatio` 배율로 그림과 한글 이름이 또렷하게 렌더링
- **이름이 크게 보이는 배치**: 세로 화면 3열×6줄(또는 4줄), 넓은 화면 6열×3줄 — 벽돌 폭에 맞춰 글자 크기를 자동 계산
- **사운드 합성**: Web Audio API로 만든 효과음(외부 오디오 파일 없음), 🔊 버튼으로 끄고 켜기(설정 저장)
- **공유**: 시작/종료 화면의 "링크 복사" 버튼, 모바일에서는 기본 공유 시트
- 최고 점수는 브라우저에 저장됩니다.
