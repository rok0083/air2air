# 🧱 삼성고동문회 벽돌깨기

이택형 · 성승현 · 우상봉 · 강현수 · 황진석 · 강동균 — 여섯 동문의 이름을 벽돌로 세워 두고 깨는 모바일 벽돌깨기 게임입니다.

**플레이:** https://rok0083.github.io/air2air/samsung-high-brick-breaker/

카카오톡으로 링크를 보내면 미리보기 카드(제목·설명·썸네일)와 함께 열립니다.

## 게임 방법

- 화면 아무 곳이나 **드래그**하면 패들이 따라옵니다.
- **탭**하면 공이 발사됩니다.
- 벽돌을 깨면 점수가 오르고, 패들에 닿기 전까지 연속으로 깨면 **콤보 배수**가 붙습니다(최대 x5).
- 3개의 스테이지를 모두 깨면 클리어. 위쪽 벽돌은 여러 번 맞혀야 깨집니다.
- 생명은 3개(♥♥♥). 공을 놓치면 하나씩 줄어듭니다.
- 데스크톱에서는 ←/→ (또는 A/D)로 패들, Space로 발사, P/Esc로 일시정지.

## 아이템 벽돌 & 장착 무기

- 벽돌판에는 **빛나는 테두리와 아이콘**이 있는 아이템 벽돌이 섞여 있습니다(스테이지마다 2~3개).
- 그 벽돌을 깨면 **아이템 캡슐**이 아래로 떨어집니다. 패들로 받으면 무기가 **자동 장착**됩니다.
  - **🔫 총알** — 10초 동안 0.25초마다 패들 양쪽에서 총알이 자동 발사됩니다(한 발에 벽돌 1타).
  - **⚡ 레이저** — 8초 동안 0.55초마다 패들 위로 강력한 레이저가 발사되어, 그 세로줄의 벽돌을 **관통**합니다(2타).
- 장착 중에는 상단 스코어보드의 **ITEM 칸에 남은 시간 게이지**가 줄어들고, 패들에 포신·발광체가 붙습니다.
- 자동 발사라서 오른손 한 손가락 드래그만으로 편하게 플레이할 수 있습니다.

## 상단 스코어보드

`SCORE` · `BEST`(최고 점수) · `STAGE` · `COMBO`(배수) · `LIVES` · `ITEM`(무기 + 남은 시간 바).
스테이지 클리어/게임 오버 화면에는 **점수 · 최고 점수 · 최대 콤보 · 깬 벽돌 수 · 남은 생명(도달 스테이지)** 요약판이 표시됩니다.

## 특징

- **작은 벽돌·촘촘한 격자**: 세로 모바일 6열×6~8줄, 넓은 화면 7~8열 — 벽돌 크기에 맞춰 한글 이름 글자 크기를 자동 계산해 또렷하게 유지
- **스테이지 배경 사진**: 게임 중에는 지금 스테이지의 동문 사진이 벽돌 뒤로 은은하게 깔리고, 스테이지 클리어·올클리어 순간에는 색종이·불꽃과 함께 사진이 크게 공개됩니다. 아래 스코어 카드는 반투명 유리 카드라 사진 속 얼굴을 가리지 않으며, `🖼️ 사진 보기` 버튼으로 카드를 접고 사진만 볼 수 있습니다.
- **아케이드 연출**: 점수 팝업(+점수), `COMBO xN!` 팝업, 타격 스파크·파편, 공 잔상, 패들 발광, 화면 흔들림
- **모바일 최적화**: `100dvh` 세로 화면, `touch-action: none`으로 드래그 중 스크롤·당겨서 새로고침 없음, 안전영역(`safe-area-inset`) 대응
- **고해상도 캔버스**: `devicePixelRatio` 배율로 그림과 한글 이름이 또렷하게 렌더링
- **사운드 합성**: Web Audio API로 만든 효과음(발사음·레이저음 포함, 외부 오디오 파일 없음), 🔊 버튼으로 끄고 켜기(설정 저장)
- **공유**: 시작/종료 화면의 "링크 복사" 버튼, 모바일에서는 기본 공유 시트
- 최고 점수는 브라우저에 저장됩니다.
