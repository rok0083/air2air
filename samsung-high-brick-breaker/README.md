# 🧱 삼성고동문회 벽돌깨기

이택형 · 성승현 · 우상봉 · 강현수 · 황진석 · 강동균 — 여섯 동문의 이름을 벽돌로 세워 두고 깨는 모바일 벽돌깨기 게임입니다.

**플레이:** https://rok0083.github.io/air2air/samsung-high-brick-breaker/

카카오톡으로 링크를 보내면 미리보기 카드(제목·설명·썸네일)와 함께 열립니다.

## 게임 방법

- 화면 아무 곳이나 **드래그**하면 패들이 따라옵니다.
- **탭**하면 공이 발사됩니다.
- 벽돌을 깨면 점수가 오르고, 패들에 닿기 전까지 연속으로 깨면 **콤보 배수**가 붙습니다(최대 x5).
- **99 스테이지**에 도전! 홀수 스테이지는 일반, **짝수 스테이지는 보너스 스테이지**입니다. 위쪽 벽돌은 여러 번 맞혀야 깨집니다.
- 생명은 3개(♥♥♥). 공을 놓치면 하나씩 줄어듭니다.
- 데스크톱에서는 ←/→ (또는 A/D)로 패들, Space로 발사, P/Esc로 일시정지.

## 아이템 벽돌 & 장착 무기

- 벽돌판에는 **빛나는 테두리와 아이콘**이 있는 아이템 벽돌이 섞여 있습니다(스테이지마다 5~7개).
- 그 벽돌을 깨면 **아이템 캡슐**이 아래로 떨어집니다. 패들로 받으면 즉시 발동됩니다.
  - **🔫 총알** — 10초 동안 0.25초마다 패들 양쪽에서 총알이 자동 발사됩니다(한 발에 벽돌 1타).
  - **⚡ 레이저** — 8초 동안 0.55초마다 패들 위로 강력한 레이저가 발사되어, 그 세로줄의 벽돌을 **관통**합니다(2타).
  - **🔥 불** — 화염 웨이브가 솟아올라 **붉은 계열(레드·핑크) 벽돌만** 모조리 태웁니다(불꽃 폭발 연출).
  - **💧 물** — 물대포 웨이브가 **파란 계열(블루·시안) 벽돌만** 부숩니다(물보라 연출).
  - **🎱 멀티볼** — 공이 3개로 갈라집니다.
  - **🛸 와이드** — 12초 동안 패들이 1.5배로 넓어집니다.
  - **🛡️ 실드** — 10초 동안 바닥에 발광 에너지 막이 생겨, 놓친 공을 공마다 한 번씩 되살립니다.
- 장착 중에는 상단 스코어보드의 **ITEM 칸에 남은 시간 게이지**가 줄어들고, 패들에 포신·발광체·에너지 막이 붙습니다.
- 자동 발사라서 오른손 한 손가락 드래그만으로 편하게 플레이할 수 있습니다.

## 보너스 스테이지 & 랭킹

- **★ BONUS STAGE ★ (짝수 스테이지)** — 일반 벽돌이 10초짜리 **황금 배수 벽돌(×2·×3·×4·×10)** 로 바뀝니다. 10초 안에 깨면 점수에 배수가 붙고, 못 깨면 원래 벽돌로 돌아갑니다(다른 벽돌이 계속 새로 바뀝니다).
- **Top 6 랭킹 (실시간 전체 랭킹)** — 시작 화면에서 이름(한글 5자)을 넣고 플레이하면 점수가 **Firebase Realtime Database**로 전송되어, 링크를 받은 동문 누구와도 **같은 순위판**을 실시간으로 공유합니다. 게임 중 점수가 1위를 넘으면 `🏆 최고 점수 갱신!`, 순위에 들면 `🔥 N위 등극!` 알림이 뜨고 HUD `1위` 칸은 항상 **전체 1위 점수**를 보여줍니다. 상단 `🏆` 버튼으로 언제든 순위판을 열어볼 수 있고, 다른 동문이 기록을 올리면 순위판이 **실시간으로 갱신**됩니다(연결이 끊기면 이 기기 캐시로 계속 플레이).
- **내 기록은 Top 6 밖이어도 보입니다** — 순위판 아래에 `내 기록 2,184 · 전체 7위 / 11명` 처럼 내 최고 점수와 전체 순위가 항상 함께 나옵니다. 새로고침해도 그대로 남습니다.
- **저장은 확인될 때까지 다시 보냅니다** — 점수는 먼저 이 기기에 저장되고(대기열), 서버가 확인하면 완료됩니다. 전송이 실패하면 순위판에 `저장 중…` 으로 표시되고 간격을 늘려가며 자동 재전송, 탭을 나가거나 새로고침하는 순간에는 즉시 전송합니다.

## 상단 스코어보드

`SCORE` · `1위`(전체 1위 점수) · `STAGE` · `COMBO`(배수) · `LIVES` · `ITEM`(무기 + 남은 시간 바).
스테이지 클리어/게임 오버 화면에는 **점수 · 내 최고 · 최대 콤보 · 깬 벽돌 수 · 남은 생명(도달 스테이지)** 요약판이 표시됩니다.

## 특징

- **작은 벽돌·촘촘한 격자**: 세로 모바일 1스테이지 6열×7줄 → 2스테이지 7열×8줄 → **3스테이지 8열×10줄(80개)**, 넓은 화면은 8~10열 — 벽돌 크기에 맞춰 한글 이름 글자 크기를 자동 계산해 또렷하게 유지
- **단계별 난이도**: 3스테이지는 벽돌이 더 작고 많으며 단단한 벽돌(2~3타)이 크게 늘고 공 속도도 1.22배로 빨라집니다.
- **스테이지 배경 사진**: 게임 중에는 지금 스테이지의 동문 사진이 벽돌 뒤로 은은하게 깔리고, 스테이지 클리어·올클리어 순간에는 색종이·불꽃과 함께 사진이 크게 공개됩니다. 아래 스코어 카드는 반투명 유리 카드라 사진 속 얼굴을 가리지 않으며, `🖼️ 사진 보기` 버튼으로 카드를 접고 사진만 볼 수 있습니다.
- **아케이드 연출**: 점수 팝업(+점수), `COMBO xN!` 팝업, 타격 스파크·파편, 공 잔상, 패들 발광, 화면 흔들림
- **모바일 최적화**: `100dvh` 세로 화면, `touch-action: none`으로 드래그 중 스크롤·당겨서 새로고침 없음, 안전영역(`safe-area-inset`) 대응
- **고해상도 캔버스**: `devicePixelRatio` 배율로 그림과 한글 이름이 또렷하게 렌더링
- **사운드 합성**: Web Audio API로 만든 효과음(발사음·레이저음 포함, 외부 오디오 파일 없음), 🔊 버튼으로 끄고 켜기(설정 저장)
- **공유**: 시작/종료 화면의 "링크 복사" 버튼, 모바일에서는 기본 공유 시트
- 최고 점수는 브라우저에도 저장되고, 전체 랭킹 기록은 Firebase에 저장됩니다.
