# 헥사 킹덤 (HEXA KINGDOM) 🏰

> 견습 기사 **루크(Luke)** 와 요정 **피피(Pipi)** 가 그림자 군주의 저주로 잠든 **5개 월드**를
> 매치3 퍼즐로 되살리는 모바일 세로형 어드벤처입니다.
> **100개의 마을 복구 과제**, **100개 스테이지**, 주간 블리츠, 우리 방 랭킹까지.

- **플레이** : https://rok0083.github.io/air2air/hexa-kingdom/
- **기술** : HTML5 Canvas + Vanilla JS (ES Modules, 빌드 없음) + Firebase v10 (익명 로그인 · Firestore)
- **화면** : 모바일 세로 우선. 데스크톱에서는 가운데 480px 로 정렬됩니다.

## 1. 게임 소개

그림자 군주가 왕국 다섯 곳에 저주를 흩뿌렸습니다. 루크와 피피는 보석을 잇는 마법으로
저주를 풀고, 마을과 건물을 하나씩 되살립니다. 각 월드의 끝에는 그림자 군주의 부하가
지키는 **보스 스테이지**가 있습니다.

| 월드 | 이름 | 저주 | 장애물 |
| --- | --- | --- | --- |
| 1 | 푸른 초원 Emerald Meadow | 시든 풀과 잠든 마을 | 덤불(1~2단) · 나무 상자(2단) · 풀밭 |
| 2 | 얼음 왕국 Frost Kingdom | 얼어붙은 항구와 눈보라 | 얼음 블록(2단) · 눈사람(3단) · 고드름 |
| 3 | 불타는 사막 Scorched Desert | 타오르는 모래와 메마른 우물 | 모래 번짐 · 항아리 · 선인장 |
| 4 | 수정 정글 Crystal Jungle | 뒤엉킨 덩굴과 잠든 열매 | 덩굴 · 열매 나무 · 늪 |
| 5 | 그림자 성 Shadow Castle | 그림자 군주의 저주 | 그림자 돌 · 그림자 룬 + 보스 소환 |

- **보스** : 슬라임 경비대장 → 눈보라 골렘 → 사막의 스핑크스 → 그림자 덩굴 → **그림자 군주**
- 모든 이름·캐릭터·SVG/Canvas 아트·UI 는 이 게임만의 오리지널입니다.

## 2. 조작과 규칙

| 조작 | 방법 |
| --- | --- |
| 보석 교체 | 보석을 **스와이프**(상하좌우) 하거나 **두 번 탭** |
| 부스터 | 하단 버튼 → 사용할 칸 탭 |
| 힌트 | 💡 버튼 (5초 무입력 시 자동 힌트) |

- 8×8 보드, 5~6가지 색. 색약 접근성을 위해 **모양도 색마다 다릅니다**(원·다이아·사각·삼각·육각·별).
- 인접한 두 보석을 바꿔 3개 이상 잇으면 제거 → 낙하 → 보충 → **연쇄**.
- 매치가 안 되는 교체는 되돌아옵니다.
- 이동 수를 모두 쓰면 패배. 코인으로 **+5 이동** 이어하기(최대 2회).
- 스테이지 목표 4종: **색 보석 모으기 · 장애물 없애기 · 마법 씨앗 바닥까지 떨어뜨리기 · 보스 HP 0**.

### 특수 보석
| 특수 보석 | 만드는 매치 | 효과 |
| --- | --- | --- |
| 🚀 로켓 | 4개 일렬 | 가로 또는 세로 한 줄 제거 |
| 🧨 TNT | L / T 자 | 3×3 폭발 |
| 🌀 프로펠러 | 2×2 사각 | 십자 제거 + 목표 지점으로 날아가 3×3 |
| ⚡ 전기구 | 5개 이상 일렬 | 같은 색 보석 전부 제거 |

### 콤보 (특수 + 특수 교체)
로켓+로켓(십자) · 로켓+TNT(3줄+3열) · TNT+TNT(5×5) · 프로펠러+프로펠러(3개 분열) ·
로켓+프로펠러 · TNT+프로펠러(복제) · 전기구+로켓/TNT/프로펠러(같은 색 전부 변환) ·
전기구+전기구(보드 전체) — **총 10조합**, 닿은 특수 보석은 **연쇄 발동**합니다.

### 부스터 (v2 = 8종)
- 인게임 기본: 망치(칸 제거) · 드릴(세로줄 관통) · 폭탄(3×3) · 마법 모자(같은 색 전부 특수로)
- 인게임 전술(신규): **자유 교체**(이동 수 없이 이웃 두 보석 교체) · **번개 지팡이**(가로+세로+대각선 8방향)
  · **무지개 프리즘**(칸 하나를 전기구로 바꿔 즉시 발동) · **시간 모래시계**(이동 +3)
- 시작 전: 시작 로켓 · 시작 폭탄 · 시작 프로펠러
- 연승 보너스: 3연승 로켓+1 / 5연승 로켓+2 / 7연승 로켓+2·폭탄+1
- 부스터 바는 8+힌트를 **가로 스크롤**로 보여 줍니다(390px 화면에서도 잘리지 않음).

### 보너스 보석 (v2)
연쇄 2단계 이상 또는 3수마다 가끔 보드에 나타나고, 그 보석을 매치하면 발동합니다.

| 보너스 | 효과 |
| --- | --- |
| 코인 보석 | 코인 +50 |
| 이동 보석 | 이동 수 +2 |
| 별빛 타격 | 목표 2개 자동 타격(목표 색·장애물 우선) |
| 2배 점수 | 다음 3수 점수 2배 |

## 3. 메타(왕국 복구)

- **월드 지도** : 5월드 × 4구역 × 5과제 = **100개 복구 과제**. 스테이지를 깨서 모은
  **망치 토큰**으로 마을을 복구하면 코인·경험치를 받습니다(복구 연출 포함).
- **성장** : 경험치 → 플레이어 레벨(최대 60). 레벨업 시 목숨 +1.
- **목숨** : 최대 5개, **15분마다 1개 회복**.
  **스테이지를 시작할 때는 목숨을 쓰지 않습니다.** 실패했거나(이동 1회 이상 둔 뒤) 중도 포기했을 때만
  1개가 줄어들어, 이길 때까지 계속 이어서 플레이할 수 있습니다. 레벨업 시 +1,
  0개가 되면 코인 400으로 바로 가득 충전할 수 있습니다(출발 준비 모달·목숨 모달).
- **코인** : 클리어·별·연승·복구·블리츠로 획득. 상점에서 단품/3개 묶음/레벨업 상자/구역 상자/목숨 회복 구매.
- **주간 블리츠** : 60초 동안 최고 점수 도전, 매주 월요일 초기화.
- **랭킹 4탭** : 진행 레벨 / 총 별 / 주간 블리츠 / **우리 방**(6자리 코드, `?room=CODE` 초대 링크).

## 6. 레벨과 생성기

- World 1: 20개 스테이지(장애물·목표를 순서대로 소개, 20번은 보스).
- World 2~5: 각 20개(1~5번은 손수 설계한 소개·보스 샘플, 6~20번은 규칙 생성).
- 모든 레벨은 생성 직후 **시작 보드에 즉시 매치 없음 / 가능한 수 1개 이상 / 막힌 칸 35% 이하**를
  자체 검증합니다(`analysis.validated`).

```bash
node tools/level-generator.mjs --world 1 --out levels      # 월드 1 생성
node tools/level-generator.mjs --all --out levels          # 100개 생성
node tools/level-generator.mjs --world 3 --level 7         # 한 개를 JSON으로 출력
```

자세한 필드는 [LEVEL_SCHEMA.md](LEVEL_SCHEMA.md) 참고.

## 7. Firebase (기존 프로젝트 재사용)

`hexa` 블리츠와 **같은 프로젝트**(`samsung-brick-breaker`)를 쓰되 컬렉션을 분리했습니다.

| 컬렉션 | 용도 | 규칙 |
| --- | --- | --- |
| `scores` | 헥사 블리츠 기존 점수 | **변경 없음(그대로 유지)** |
| `users/{uid}` | 헥사 킹덤 프로필(진행도·별·코인·방 코드) | 읽기 공개 / 본인만 생성·수정 / 본인만 삭제 |
| `blitzScores/{id}` | 주간 블리츠 점수 | 읽기 공개 / 본인 점수만 생성 / 수정 불가 / 본인 삭제 |

- **익명 로그인만** 사용합니다. 첫 실행에서 닉네임을 받아 `users/{uid}` 에 저장하고,
  이후에는 세션이 복원되어 바로 월드 지도로 들어갑니다. 닉네임 변경은 설정에서만 가능합니다.
- 진행도는 `localStorage` 에 먼저 저장되고, 연결되면 `updatedAt` 기준으로 서버에 병합됩니다.
  오프라인이면 대기열에 넣었다가 복구 시 재전송합니다.
- 보안 규칙·색인 파일은 이 폴더에 있으며, 기존 `scores` 규칙과 색인은 **병합만** 했습니다.

### 배포(참고)

```bash
npm i -g firebase-tools && firebase login
firebase deploy --only firestore:rules,firestore:indexes --project samsung-brick-breaker
```

현재 배포된 규칙은 Firebase 콘솔 > Firestore > 규칙 에서 확인할 수 있습니다.

## 9. 크레딧

원본 IP · 코드 · 아트 : 우상봉의 Pickle 과 함께 만든 오리지널 게임.
사운드는 모두 Web Audio API 로 실시간 합성하며 외부 음원을 쓰지 않습니다.
